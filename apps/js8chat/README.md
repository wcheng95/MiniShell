# JS8Chat MiniShell app

Status: **v0.1 architecture frozen; implementation not started.**

JS8Chat is a compile-in MiniShell application, parallel in role to `apps/ft8`.

This directory currently contains only implementation-support assets:

- `tools/` — app-specific generators/reference utilities;
- `resources/` — checked-in generated JSC reference data.

Application source/include/main directories will be added when implementation starts.

Canonical design documentation lives under `docs/js8/`.
The frozen interoperability reference is JS8Call-improved `v3.0.3`.
