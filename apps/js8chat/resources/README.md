# JS8Chat generated JSC resources

`jsc.dict` and `jsc.dict.meta.json` are generated by:

```text
apps/js8chat/tools/extract_jsc_dict.py
```

Frozen upstream reference:

- repository: `JS8Call-improved/JS8Call-improved`
- release/tag: `v3.0.3`
- file: `JS8_JSC/JSC_map.cpp`
- upstream license: GPL-3.0-or-later

The complete v3.0.3 262,144-entry receive map was verified byte-for-byte against the earlier historical map used during JS8Chat research. The resulting JSC1 binary is unchanged:

```text
size:   1,918,009 bytes
sha256: ced6b30303f004966b29f7e658e7e60c8933526716b1b85c03384d0e9a417149
```

The checked-in binary currently contains the RX `index -> Latin-1 string` mapping. TX JSC support will add compact upstream-equivalent lookup/consume-length data without duplicating the string corpus.

See `docs/js8/jsc-dictionary.md`.
